# AllGames

This is a collection of small C++/SFML-based games I developed while learning different aspects of game programming.  
Each project focuses on a specific skill, from input handling and logic to basic engine architecture and interactive storytelling.  
One additional unfinished project represents a level editor concept I began building before switching to Unity.

---

## Included Games

### 1. **Minesweeper Clone**

- A faithful implementation of the classic Minesweeper game.
- Features:
  - Three levels of difficulty
  - Randomized board generation
  - Win/loss conditions
  - GUI made with SFML
- Purpose: Practice in implementing grid-based logic and game states.

---

### 2. **RevoGame (Joke Game for Friends)**

- A humorous mini-project intended for internal use with friends.
- Features:
  - Basic player movement using keyboard
  - Simple character animation or sprite logic
- Purpose: First steps in handling input, movement, and sprite drawing in SFML.

---

### 3. **Escape from the Basement (Horror Adventure)**

- A more serious interactive horror game with story elements.
- Features:
  - First-person perspective with static photo backgrounds
  - Item interaction via mouse input
  - Story-driven progression with decision-based events
  - Inventory and simple puzzle-solving mechanics
- Purpose: Learn point-and-click mechanics, user interaction, and narrative design.

---

### 4. **Tetris Clone**

- A playable Tetris implementation with music.
- Features:
  - Falling blocks with full rotation and placement logic
  - Line clearing and scoring
  - Background music playback using SFML audio module
- Purpose: Learn timing, falling block mechanics, and audio integration.

---

### 5. **Prototype: Level Builder (Unfinished)**

- An early attempt at developing a visual level editor using SFML.
- Goal:
  - Place sprites manually on a canvas
  - Save object positions for future use
- Development of this tool was paused when I transitioned to Unity development.

---

## Technologies

- **C++**
- **SFML (Simple and Fast Multimedia Library)**
- Standard Library (`<vector>`, `<map>`, etc.)

---

## Notes

- Most projects can be compiled using any standard C++ compiler with SFML linked.
- No external dependencies beyond SFML.
- All code was written manually without a game engine.

---

## Purpose of the Repository

This collection represents my early journey into game development.  
It helped me:
- Practice core programming concepts (input, logic, rendering)
- Explore different genres (puzzle, horror, arcade)
- Build small-scale tools and systems from scratch
- Prepare for switching to Unity and more advanced environments
